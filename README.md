# Career OS｜职业成长与作品集

## 项目介绍

这个仓库是个人职业资产的系统化沉淀，用于持续整理职业定位、简历版本、项目案例、运营体系、AI 数字化规划、行业研究与个人主页内容。它不是代码仓库说明，而是一个面向业务经营、能力复盘与职业发展的 Career OS。

## 核心能力

- 商业化落地：连接技术、产品与经营结果，推动自动驾驶观光车项目从技术展示走向商业运营。
- P&L 与业务经营：围绕收入增长、成本控制与盈利模型建设，对项目经营结果负责。
- 多项目管理：在多景区、多车辆资产、多区域场景下推进规模化运营与项目复制。
- 运营体系建设：沉淀项目运营、安全管理、车辆调度、培训与应急响应 SOP。
- 团队管理：建设并管理运营团队，形成培训、排班、绩效与现场执行体系。
- 数字化与 AI 增强运营：通过数据分析、财务模型、智能调度与 AI 工具探索提升运营效率。
